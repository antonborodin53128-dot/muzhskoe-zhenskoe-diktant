ДИКТАНТ v7 WEB
- Пульт ведущего на телефоне снова компактный и удобный.
- Во время игры убран постоянный список участников/очков с пульта.
- У ведущего остаются: текущее слово, текущий участник, ввод, озвучка, таблица, завершение.
- Звук переделан на Web Audio API.
- Гостевой экран один раз активирует звук кнопкой; дальше используется постоянный AudioContext.
- MP3 загружаются и декодируются на гостевом устройстве, команды запуска приходят от ведущего.
- API state запрашивается без кеширования.
